# 量化系统架构文档

版本：v1.1  
定位：1 个出资人 + 6 人团队，资金规模约1亿人民币。波段交易为主，看长做短，高抛低吸，免费数据源可落地  
数据边界：只假设可长期使用 AKShare、pytdx、交易所/巨潮等免费公开信息；不依赖 Wind、聚宽、米筐、同花顺 iFinD、Choice、Level-2、券商专有数据。  
核心目标：先搭出可采集、可回测、可复现、可风控、可影子实盘、可小资金半自动实盘的闭环。

---

## 1. 最终结论

这套系统可以落地，但必须承认免费数据的边界：

- 可以做：A 股日频量价、复权、指数、基础财务、行业、停牌/ST/涨跌停、公告摘要、简单资金流、波段因子、LightGBM/XGBoost、TopN 组合、影子实盘、小资金半自动交易。
- 谨慎做：北向资金、融资融券、龙虎榜、公告事件、行业分类、分钟线。它们在免费源里可能有缺失、口径变化或历史深度不足，必须可选、可降级。
- 不做或不作为一期依赖：Level-2 逐笔委托、真实盘口队列、稳定实时 VWAP、机构持仓高频变化、完整新闻全文、全市场可靠实时资金流、券商专有交易回报接口。

一期策略应定位为：

```text
免费公开数据 + 日频波段多因子 + 中期择势 + 短期低吸/高抛 + TopN 组合 + 严格风控 + 影子实盘验证
```

不要把免费数据系统设计成机构级全数据平台。正确做法是把所有“不稳定/拿不到/口径不确定”的数据都放进可选层，主链路只依赖高可得数据。

### 1.1 策略风格定义

本方案不做日内、不做高频，不追求分钟级交易优势。策略风格统一定义为：

```text
看长：用 20-120 日趋势、行业强弱、估值/财务质量、市场环境判断股票是否值得进入候选池。
做短：在候选池内等待 3-20 日级别回撤、缩量、接近均线或风险释放后的低吸机会。
高抛：当短期涨幅过大、偏离均线过高、风险升高或达到目标收益时分批减仓。
低吸：当中期趋势未破坏、流动性合格、短期回撤到合理区域时分批买入。
```

典型持仓周期建议为 `5-30 个交易日`，少数强趋势持仓可延长到 `60 个交易日`。组合不追求高换手，默认每周评估 1 次，触发条件满足时再调仓。

## 2. 免费数据可得性审计

### 2.1 可作为主链路依赖的数据

这些数据可以作为系统一阶段的核心依赖。

| 数据 | 来源 | 用途 | 可得性 | 处理原则 |
|---|---|---|---|---|
| A 股股票列表 | AKShare / pytdx | 股票池、代码映射 | 高 | 每日更新，保留退市/停牌状态 |
| 交易日历 | AKShare / 本地维护 | 任务调度、回测 | 高 | 本地落库，人工可修正 |
| 日线行情 OHLCV | AKShare / pytdx | 因子、回测、标签 | 高 | 双源抽样校验 |
| 复权行情/复权因子 | AKShare / 自算校验 | 收益率、因子 | 中高 | 固定前复权口径，异常跳点复核 |
| 指数日线 | AKShare / pytdx | 基准、Beta、行业中性辅助 | 高 | 至少沪深300、中证500、中证1000 |
| 涨跌停价格/状态 | AKShare / 自算 | 风控、回测成交 | 中高 | 优先采集，缺失时按规则自算 |
| ST 状态 | AKShare | 股票池过滤 | 中高 | 名称含 ST 只是兜底，需每日记录 |
| 停牌状态 | AKShare / pytdx | 过滤、成交模拟 | 中 | 用成交量、行情缺失、状态表交叉判断 |
| 基础财务指标 | AKShare | 基本面因子 | 中 | 必须按公告日或可得日期入库 |
| 行业分类 | AKShare | 行业中性、行业约束 | 中 | 口径固定后版本化 |

### 2.2 可选使用、不能阻塞主链路的数据

这些数据可以提升效果，但不能作为系统能否运行的前提。

| 数据 | 免费源问题 | 用法 |
|---|---|---|
| 主力资金流 | 口径可能来自第三方页面，稳定性和历史深度不确定 | 作为可选因子，缺失时置空 |
| 北向资金 | 免费源历史、口径、覆盖可能不稳定 | 可做市场级/个股级辅助，不阻塞模型 |
| 融资融券 | 交易所口径可得但覆盖有限，更新可能延迟 | 可做风险/情绪因子 |
| 龙虎榜 | 只覆盖上榜股票，稀疏 | 事件型特征，不做主因子 |
| 公告全文 | 免费接口可能只有标题/链接/摘要，正文质量不稳 | LLM 只做辅助摘要和人工复核 |
| 解禁/回购/分红 | 免费源可能缺字段或口径变化 | 能采则用，缺失不阻塞 |
| 分钟线 | pytdx 可取，但历史深度、稳定性、补全成本更高 | 不进入主链路；仅用于人工复盘或成交价格研究 |

### 2.3 从原方案中降级或删除的数据

| 原数据/功能 | 问题 | 最终处理 |
|---|---|---|
| `northbound_change_5d` | 免费个股北向历史不保证稳定 | 移到可选因子，缺失不入主模型 |
| `main_money_flow_1d/5d` | 资金流口径不透明 | 移到可选因子，只做辅助 |
| `dragon_tiger_net_buy` | 稀疏且非全市场 | 改为事件 flag，不做连续数值主因子 |
| 真实 VWAP 成交 | 免费日频源不稳定提供真实 VWAP | 回测默认用次日开盘价或均价假设加滑点，不依赖分钟线 |
| 实时快照 | 免费源稳定性不足 | 只做人工观察，不参与自动交易决策 |
| 新闻去重/历史相似新闻 | 免费新闻全文不可稳定依赖 | 改为公告/标题/摘要级辅助 |
| 深度盘口模型 | 需要 Level-2 或高质量盘口 | 一期删除 |
| 自动交易中台 | 需要券商接口和权限 | 一期半自动 CSV/Excel |

## 3. 最终系统边界

### 3.1 一期必须实现

- 数据采集：股票列表、交易日历、日线行情、复权、指数、ST/停牌/涨跌停、基础财务、行业分类。
- 数据仓库：raw、clean、feature、trade 四层。
- 因子库：30-60 个高可得波段因子，以中期趋势、短期回撤、波动风险、流动性、基础估值、财务质量、行业强弱为主。
- 模型：Ridge baseline + LightGBM ranking/regression。
- 回测：支持成本、滑点、涨跌停、停牌、ST、100 股、现金不足。
- 组合：股票池过滤、趋势候选池、低吸/高抛信号、TopN、行业约束、单票约束、换手约束。
- 风控：数据异常阻塞、计划单审批、逐票拦截原因。
- 影子实盘：至少 20-40 个交易日。
- 小资金执行：CSV/Excel 半自动交易，盘后导入成交回报。

### 3.2 一期可选实现

- 分钟线人工复盘或成交价格研究。
- 资金流、北向、融资融券、龙虎榜、公告事件。
- LLM 公告摘要、事件分类、归因报告草稿。
- 简单 Grafana 看板。

### 3.3 一期明确不做

- 日内交易、高频交易、盘口模型、Level-2 特征。
- 每股 LoRA 或自训练大模型。
- 全自动交易中台。
- Kubernetes、全量微服务。
- 依赖收费数据才能运行的因子。

## 7. 数据质量和免费源降级规则

### 7.1 质量检查

| 检查项 | 阈值 | 失败动作 |
|---|---:|---|
| 交易日历存在当日 | 必须 | 阻塞计划单 |
| 日线行情覆盖率 | >= 99% 活跃股票 | 阻塞计划单 |
| OHLC 合法性 | 100% | 异常股票剔除 |
| 成交量/成交额非负 | 100% | 异常股票剔除 |
| AKShare/pytdx 收盘价抽样差异 | <= 1bp 或有解释 | 超阈值阻塞 |
| 复权收益异常 | 非涨跌停日 abs(ret) <= 30% | 人工复核 |
| 财务 publish_date | 不为空 | 缺失不得入特征 |
| 核心因子覆盖率 | >= 95% 核心股票池 | 低覆盖因子禁用 |

### 7.2 数据降级

```text
核心数据失败：交易日历、日线行情、复权、股票状态
  -> 阻塞计划单，只输出诊断报告

增强数据失败：资金流、北向、融资融券、龙虎榜、公告事件
  -> 主流程继续，相关因子置空或禁用

分钟线失败：
  -> 不影响主流程；波段策略主链路不依赖分钟线

LLM/API 失败：
  -> 不影响交易，只跳过摘要和事件分类
```

### 8.3 防未来函数规则

- `T` 日收盘后生成 `T+1` 计划单，不做盘中信号追单。
- `T` 日因子只能使用 `T` 日收盘后已公开可得数据。
- 财务数据必须使用 `publish_date <= T` 的最新值。
- 公告事件必须使用 `publish_time <= T 15:30` 或明确在收盘后处理为次日可用。
- 行业分类、ST、停牌状态必须按日期版本化。
- 所有滚动窗口不包含未来值。

---

## 9. 标签、模型和训练

### 9.1 标签

```text
forward_return_10d = adj_close(T+10) / adj_close(T+1) - 1
forward_return_20d = adj_close(T+20) / adj_close(T+1) - 1
industry_forward_return_20d = 所属行业同期间等权收益
label_20d = forward_return_20d - industry_forward_return_20d
label_rank = 当日横截面 label_20d 分位排名
pullback_entry_label = T+1 后 5-20 日是否出现风险可控的正收益波段
take_profit_label = T+1 后 5-20 日是否进入短期过热或回撤风险上升区
```

标签从 `T+1` 开始计算，避免使用计划生成日无法成交的价格。主模型优先学习 `10-20 日` 波段收益，`5 日` 只作为短期买卖点辅助，不作为唯一目标。

### 9.2 样本过滤

- 剔除 ST / *ST。
- 剔除停牌日。
- 剔除上市不足 120 交易日。
- 剔除最近 20 日平均成交额低于 3000 万的股票。
- 剔除涨跌停导致无法正常买卖的样本。
- 剔除核心因子缺失过多的样本。

### 9.3 模型

主模型：

```text
LightGBM ranking / regression
```

基线模型：

```text
Ridge
等权 TopN
趋势过滤 + 回撤低吸规则 TopN
```

训练切分：

```text
训练集：过去 3-5 年至 T-12个月
验证集：T-12个月至 T-6个月
样本外测试：T-6个月至 T-1个月
影子实盘：最近 20-40 个交易日
```

上线条件：

- 样本外 RankIC 均值 > 0。
- 样本外 RankIC 月度为正比例 >= 55%。
- 扣费回测优于等权基线。
- 换手率在波段交易可承受范围内，不能靠高换手堆收益。
- 行业和市值暴露可解释。
- 影子实盘至少 20 个交易日稳定。

## 10. 回测和成交规则

免费数据条件下，不假设真实 VWAP 可长期稳定获得。策略不做日内和高频，成交规则以日频可复现为准。

默认成交规则：

- `T` 日收盘后生成 `T+1` 计划单。
- 买入价默认 `T+1` 开盘价 + 滑点；保守回测可使用 `T+1` 最高价附近更差价格做压力测试。
- 卖出价默认 `T+1` 开盘价 - 滑点；保守回测可使用 `T+1` 最低价附近更差价格做压力测试。
- 不使用分钟线作为主回测依赖。
- 涨停不买。
- 跌停不卖。
- 停牌不交易。
- 100 股取整。
- 单票成交额不超过当日成交额 3%-5%，超过部分视为未成交。
- 现金不足时按目标权重优先级成交，剩余订单失败。

成本参数：

```text
佣金：双边 3bp，最低 5 元，可按券商实际调整
印花税：卖出 5bp，以实际政策为准
滑点：单边 5bp 起
冲击成本：订单额超过当日成交额 1% 后额外增加 5-20bp
```

回测报告：

- 年化收益、波动、夏普、最大回撤。
- 超额收益、信息比率。
- 月度收益。
- 换手率、交易成本、滑点。
- 行业贡献、个股贡献、因子贡献。
- 风控拦截统计。
- 与沪深300、中证500、中证1000、等权基线对比。

## 11. 组合和风控

组合流程：

```text
核心股票池
  -> 剔除 ST / 停牌 / 上市不足 / 低流动性
  -> 中期趋势和行业强弱过滤
  -> 读取 alpha_score
  -> 合并 trend_score / pullback_score / risk_score / liquidity_score
  -> 低吸候选和高抛候选识别
  -> 行业分层
  -> TopN 建仓/加仓/减仓
  -> 等权或波动率倒数加权
  -> 换手和持仓周期控制
  -> 风控检查
  -> 计划单
```

默认参数：

| 项目 | 默认值 |
|---|---:|
| 持仓数量 | 50-100 |
| 单票上限 | 2%-3% |
| 行业上限 | 20%-25% |
| 现金保留 | 2%-5% |
| 单日换手上限 | 10%-20% |
| 单票成交占当日成交额 | <= 3%-5% |
| 调仓频率 | 每周 1 次为主，触发止盈/止损/风控时临时调仓 |
| 典型持仓周期 | 5-30 个交易日 |
| 强趋势最长观察周期 | 60 个交易日 |

硬风控：

- 数据质量失败，不生成计划单。
- ST、停牌、上市不足 120 日，不买入。
- 涨停不买，跌停不卖。
- 成交额过低，不买入。
- 单票、行业、换手、现金超过限制，自动截断或阻塞。
- 中期趋势破坏或跌破止损线，进入减仓/清仓候选。
- 短期涨幅过大、偏离均线过高或达到目标收益，进入高抛候选。
- 重大负面公告只做人工复核，不由 LLM 自动决定交易。

## 12. LLM 和事件辅助

LLM 只做辅助，不进入自动交易闭环。

可做：

- 公告标题/摘要整理。
- 事件分类。
- 利好/利空/中性初筛。
- 每日归因报告草稿。
- 历史相似公告检索。

不能做：

- 直接下单。
- 覆盖风控。
- 生成不可追溯的交易理由。
- 把低置信度事件写入生产模型主特征。

结构化输出：

```text
symbol
publish_time
event_type
sentiment
impact_horizon
confidence
source
url
summary
human_review_status
```

## 13. 影子实盘和小资金 SOP

### 13.1 影子实盘

每日流程：

1. 收盘后采集行情、状态、财务更新、公告。
2. 运行数据质量检查。
3. 生成中期趋势、短期低吸/高抛因子和模型预测。
4. 生成建仓、加仓、减仓、止盈、止损候选。
5. 生成组合和计划单。
6. 运行风控拦截。
7. 用模拟成交规则生成模拟成交。
8. 更新模拟持仓。
9. 输出归因报告。
10. 记录异常和处理人。

进入小资金前：

- 影子实盘连续 20 个交易日无阻塞级错误。
- 计划单、模拟成交、持仓、归因可复现。
- 完成数据缺失、涨跌停、持仓差异 3 类故障演练。
- 交易审批、执行、备份、错单处理流程明确。

### 13.2 小资金半自动实盘

流程：

1. `T` 日收盘后生成 `T+1` 计划单。
2. 交易运维核对计划单。
3. 风控负责人审批。
4. `T+1` 按审批计划导入券商系统或手工执行。
5. 盘后导入成交回报。
6. 逐票核对持仓。
7. 输出正式归因报告。
8. 异常未关闭前不得扩大资金。

默认不交易条件：

- 日线行情缺失超阈值。
- 复权或交易日历异常。
- 模型推理失败。
- 风控配置缺失。
- 计划单未经审批。
- 系统持仓和券商持仓存在未解释差异。

## 16. 最终完成定义

系统完成不是代码写完，而是满足：

- 任意交易日可以从原始数据复现因子、预测、组合、计划单、持仓和归因。
- 核心链路只依赖 AKShare/pytdx 可获得数据。
- 增强数据缺失时系统能降级运行。
- 策略定位明确为波段交易，不依赖日内信号、高频数据或分钟线优势。
- 所有计划单都有审批、风控和逐票原因。
- 影子实盘至少稳定 20 个交易日。
- 小资金至少稳定 20 个交易日后，才允许讨论扩大资金。
- 出现异常时，默认动作是“不交易”，不是人工临时猜测。
