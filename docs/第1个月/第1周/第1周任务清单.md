# 第 1 周任务清单

版本：v1.0
适用阶段：第一个月 MVP 冲刺第 1 周  

---

## 1. 第 1 周目标

第 1 周不是为了把系统做完，而是为了把团队真正启动起来，并跑通一个很粗糙但真实的最小链路。

本周目标：

```text
项目能启动
数据库/文件结构能建立
免费数据接口能访问
少量股票日线能落地
3-5 个基础因子能计算
计划单格式能确定
每个岗位知道自己接下来 3 周要交付什么
```

第 1 周结束时，最好能做到：

```text
选 20-50 只股票
拉取最近 3 年日线
生成 3-5 个基础因子
生成一个很粗糙的股票排名
形成计划单字段模板
```

这不是正式系统，只是证明大家的工作能接起来。

---

## 2. 第 1 周不做什么

本周不要做：

```text
不要追求策略收益
不要优化模型
不要做 LightGBM
不要做自动交易
不要做分钟线
不要做新闻和 LLM
不要做复杂大屏
不要研究太多可选数据源
不要把框架设计得过重
```

本周只有一个核心目标：

```text
让数据、因子、组合、计划单第一次接起来。
```

---

## 3. 第 1 周总体安排

| 日期 | 主题 | 核心产物 |
|---|---|---|
| 周一 | 启动会、定范围、定规范 | 启动会纪要、任务分配、目录结构、DDL 草案 |
| 周二 | 打通数据接口、确定字段 | 股票列表、交易日历、样例日线、字段映射 |
| 周三 | 因子和标签草案落地 | 因子定义、3-5 个因子计算、标签定义 |
| 周四 | 组合和计划单模板 | TopN 规则草案、组合参数、order_plan 模板 |
| 周五 | 第一次集成验收 | 数据到因子到计划单的粗链路验收 |

如果实际启动日不是周一，可以按“第 1 天到第 5 天”执行。

## 12. 第 1 周必须统一的最小字段口径

第 1 周不要求字段体系一次性完美，但以下字段口径必须先统一，否则后续岗位很容易接不上。

### 12.1 股票代码

建议统一使用：

```text
symbol：6 位股票代码，例如 600000、000001
exchange：交易所，例如 SH、SZ、BJ
ts_code 或 full_symbol：可选，例如 600000.SH
```

注意：

```text
不要有的人用 600000.SH，有的人用 sh600000，有的人只用 600000。
如果需要多种格式，必须明确主键格式和转换规则。
```

### 12.2 日期

建议统一使用：

```text
trade_date：YYYY-MM-DD
```

注意：

```text
不要混用 20260707、2026/07/07、datetime、字符串。
数据库里建议使用 date 类型。
CSV/Excel 里建议使用 YYYY-MM-DD。
```

### 12.3 价格和成交额

第 1 周必须确认：

```text
open/high/low/close 单位：元
volume 单位：股或手，必须写清楚
amount 单位：元，必须写清楚
```

特别提醒：

```text
不同免费接口可能 volume 单位不同，必须在 data_source_probe.md 里记录。
```

### 12.4 因子输出

因子结果最少包含：

```text
symbol
trade_date
factor_name
factor_value
factor_version
run_id
```

### 12.5 计划单输出

计划单最少包含：

```text
trade_date
account_id
symbol
stock_name
side
target_qty
target_weight
estimated_amount
order_reason
risk_check_status
risk_block_reason

```

## 13. run_id 最小规范

第 1 周先采用简单可读的 run_id，不要复杂化。

建议格式：

```text
任务名_交易日期_运行时间
```

示例：

```text
daily_after_close_20260707_20260707T183000
build_factors_20260707_20260707T184500
generate_order_plan_20260707_20260707T191000
```

run_id 至少要出现在：

```text
原始数据批次
数据质量报告
因子结果
标签结果
股票排名
目标组合
风控报告
计划单
```

第 1 周验收时，技术负责人要随机抽一只股票，沿着 run_id 检查：

```text
它的数据来自哪里
它的因子怎么生成
它的排名是多少
它是否进入组合
它是否被风控拦截
它是否进入计划单
```

```text
近期停牌或疑似停牌股票
上市时间较短的股票
至少 5 个不同行业
```

如果一开始找不到所有类型，可以先选普通股票跑通链路，但必须在 data_issue_list.md 中记录缺口。
