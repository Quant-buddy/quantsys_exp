# MVP 第 1 周启动会纪要

版本：v0.1 草案  
日期：2026-07-07  
会议主题：量化系统第一个月 MVP 冲刺启动会  
主持人：技术负责人  
状态：待团队会议确认  

---

## 1. 会议目的

本次会议用于启动第一个月 MVP 冲刺，明确：

```text
第一个月目标
第一个月不做事项
6 个岗位分工
第 1 周任务
周五验收标准
```

本次会议不讨论复杂策略收益目标，不扩展系统边界，不临时加入收费数据、日内、高频、自动交易等事项。

---

## 2. 第一个月目标

第一个月只追求主链路跑通，不追求收益最大化。

目标主链路：

```text
免费数据采集
-> 数据清洗与质检
-> 日频因子生成
-> 标签生成
-> 规则打分
-> TopN 回测
-> 组合生成
-> 风控过滤
-> T+1 计划单
```

月底必须做到：

```text
1. 免费数据能采集并落地。
2. 最近 3 年 A 股日线可复跑。
3. 至少 10 个核心因子可生成。
4. 10日/20日标签可生成。
5. 一个简单规则 TopN 策略可回测。
6. 每日可以输出 T+1 计划单。
7. 计划单有交易理由和风控状态。
8. 关键产物有 run_id，可复现。
9. 数据异常时默认不交易。
```

---

## 3. 第一个月明确不做

第一个月不做：

```text
日内交易
高频交易
Level-2 数据
分钟线主回测
券商自动下单
自动交易中台
复杂机器学习模型
LightGBM 主模型
新闻全文依赖
LLM 自动交易决策
北向资金主因子
龙虎榜主因子
融资融券主因子
复杂大屏
Kubernetes
微服务拆分
```

以上内容如有人提出，统一进入 `backlog_optional.md`，不得阻塞第一个月 MVP 主链路。

## 4. 6 个岗位分工

| 岗位 | 第一个月定位 | 第 1 周关键产物 |
|---|---|---|
| 技术负责人 | 控范围、定规范、做集成、验收主链路 | 项目骨架、DDL 草案、run_id 规范、周五验收 |
| 数据工程师 | 免费数据采集、清洗、入库、质检 | 股票列表、交易日历、20-50 只股票 3 年日线 |
| 量化研究员 | 因子、标签、股票池、规则 TopN | 股票池规则、3-5 个因子公式、标签定义 |
| 基本面/事件研究员 | 财务字段、行业分类、防未来函数 | 财务字段探查、行业样例、事件暂缓说明 |
| 策略研发工程师 | 因子计算、标签生成、排名、回测 | 3-5 个因子结果、标签样例、排名样例 |
| 组合风控/交易运维 | 组合约束、风控、计划单、SOP | 组合参数、风控规则、计划单模板 |

## 5. 第 1 周目标

第 1 周只做最小链路：

```text
样例数据
-> 3-5 个基础因子
-> 标签样例
-> 综合排名
-> TopN 组合样例
-> 风控过滤样例
-> 计划单模板
```

第 1 周结束时，至少形成：

```text
1. 项目目录结构。
2. DDL 草案。
3. configs 模板。
4. run_id 规则草案。
5. 20-50 只样例股票 3 年日线。
6. 3-5 个基础因子。
7. 10日/20日标签定义。
8. 股票排名样例。
9. TopN 组合样例。
10. order_plan 样例。
```

---

## 6. 周五验收安排

建议时间：第 1 周周五下午  
建议时长：90-120 分钟  

验收链路：

```text
数据 -> 因子 -> 标签 -> 排名 -> 组合 -> 风控 -> 计划单
```

验收结论只能是三种：

```text
通过
有条件通过
不通过
```

## 8. 技术负责人结论

第一个月不以收益率作为验收标准，而以系统闭环作为验收标准。

所有成员本周必须围绕同一条链路交付：

```text
数据 -> 因子 -> 排名 -> 组合 -> 计划单
```

不能进入这条链路的工作，本周先不做。
