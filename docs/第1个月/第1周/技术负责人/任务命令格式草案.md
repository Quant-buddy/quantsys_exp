# 任务命令格式草案

版本：v0.1

---

## 1. 基本原则

所有生产任务必须可以通过命令行运行。

不允许把 notebook 当成生产任务。

---

## 2. 第 1 个月建议任务入口

```bash
python jobs/daily_after_close.py --trade-date 2026-07-07
python jobs/build_factors.py --start 2023-01-01 --end 2026-07-07
python jobs/build_labels.py --start 2023-01-01 --end 2026-07-07
python jobs/run_backtest.py --start 2023-01-01 --end 2026-06-30
python jobs/generate_order_plan.py --trade-date 2026-07-07
python jobs/shadow_run.py --trade-date 2026-07-07
```

---

## 3. 公共参数

建议所有任务尽量支持：

```text
--trade-date
--start
--end
--config
--run-id
--dry-run
```

其中：

```text
--run-id 不传时自动生成。
--dry-run 表示只演练，不写正式结果。
```

---

## 4. 任务失败规则

```text
1. 核心数据失败，停止生成计划单。
2. 因子生成失败，停止生成计划单。
3. 风控配置缺失，停止生成计划单。
4. 非核心增强数据失败，只记录告警，不阻断主链路。
```

---

## 5. 日志要求

每个任务至少记录：

```text
任务名
run_id
开始时间
结束时间
输入参数
输出位置
成功/失败状态
错误原因
```
