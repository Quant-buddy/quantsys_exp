## 4. 每日收盘后生产流程

```mermaid
sequenceDiagram
  participant Scheduler as 调度器
  participant Data as 数据平台
  participant QA as 数据质量
  participant Factor as 因子任务
  participant Model as 模型推理
  participant Portfolio as 组合风控
  participant Trader as 交易运维
  participant Founder as 创始人/风控负责人
  participant Report as 报告归因

  Scheduler->>Data: 收盘后启动采集
  Data->>Data: AKShare/pytdx 拉取核心数据
  Data->>Data: 拉取可选增强数据
  Data->>QA: 生成质量检查
  QA-->>Scheduler: 核心数据通过/失败
  alt 核心数据失败
    Scheduler->>Report: 输出诊断报告
    Scheduler->>Trader: 通知默认不交易
  else 核心数据通过
    QA->>Factor: 计算中期趋势/短期低吸高抛因子
    Factor->>Model: 生成特征快照
    Model->>Model: 加载 model_version 推理
    Model->>Portfolio: 输出 alpha/trend/pullback/risk 分数
    Portfolio->>Portfolio: 趋势过滤/低吸高抛/权重/低换手风控
    Portfolio->>Trader: 输出计划单 CSV/Excel
    Trader->>Trader: 格式和数量复核
    Trader->>Founder: 提交审批
    Founder-->>Trader: 通过/驳回
    Trader->>Report: 记录审批和计划单
  end
```

## 6. 组合和风控流程

```mermaid
flowchart TB
  START["model_prediction + swing_signal"] --> POOL["核心股票池"]
  POOL --> F1{"是否 ST/*ST"}
  F1 -- 是 --> B1["剔除"]
  F1 -- 否 --> F2{"是否停牌"}
  F2 -- 是 --> B2["剔除/持仓延续"]
  F2 -- 否 --> F3{"上市是否满120交易日"}
  F3 -- 否 --> B3["剔除"]
  F3 -- 是 --> F4{"流动性是否达标"}
  F4 -- 否 --> B4["剔除"]
  F4 -- 是 --> TREND{"中期趋势是否健康"}

  TREND -- 是 --> ENTRY{"是否回撤到低吸区"}

  ENTRY -- 是 --> SCORE["按 alpha/trend/pullback_score 排序"]
  SCORE --> IND["行业分层"]

  TOPN --> WEIGHT["等权/波动率倒数加权"]
  WEIGHT --> R1{"单票<=3%"}
  R1 -- 否 --> CUT1["截断权重"]
  R1 -- 是 --> R2{"行业<=25%"}
  CUT1 --> R2
  R2 -- 否 --> CUT2["行业内降权"]
  R2 -- 是 --> R3{"换手<=30%"}
  CUT2 --> R3
  R3 -- 否 --> CUT3["延迟部分调仓\n保持低换手"]
  R3 -- 是 --> R4{"现金2%-5%"}
  CUT3 --> R4
```
